# Publish gx: README refresh + landing site

Goal: make `gx` presentable for a public release — refresh the README visuals and ship a one-pager
at `gx.elentok.com`.

## Decisions (from grilling session)

- **Positioning:** review-first headline (status is the #1 tab), worktrees = the parallelism layer,
  AI-code-review = the featured "why" (not the literal tagline). Hook ≈ *"a git TUI for reviewing
  changes, fast."*
- **Visual identity:** the site *is* a `gx` TUI screen — Catppuccin Mocha, bordered panels, pill
  badges, all-monospace (Nerd Font). Must **not** read as a lazygit-clone (lazygit.dev is the
  structural reference only; tig is the anti-pattern).
- **Logo:** keep original lime `docs/logo.png` as-is — the one deliberate off-palette "pop." Recolor
  to Catppuccin was tried and abandoned (washes out the shaded mascot). Pull a touch of lime into one
  site accent (primary CTA / active-tab) so it reads intentional.
- **Stack:** Vite + vanilla TypeScript + hand-written CSS. No React/Chakra. Catppuccin palette as CSS
  custom properties; Nerd Font via `@font-face`.
- **Location:** `web/` subdir in this repo, deployed standalone to Cloudflare Pages. See ADR 0012.
- **Demos:** VHS `.tape` scripts (primary) + one real screen-recording for kitty image-diffs (VHS
  can't render the graphics protocol). Single source of GIFs in `docs/`, reused by README + site.
- **README visuals:** replace the two stale static PNGs with the same animated GIFs (status, log,
  worktrees, image-diff). Single source, regenerated by `make demos`.
- **Deploy:** manual, cryptowl parity — `cd web && npm run deploy`
  (`wrangler pages deploy dist --project-name=gx`); custom domain set once in the CF dashboard.

### Page structure (top → bottom)
1. **Hero** — faux `gx` window: tagline + status demo + CTAs (Install · GitHub ★).
2. **Install in seconds** — `brew install --cask gx` / `go install …`, copy buttons.
3. **The "why" — reviewing AI code** — origin-story narrative.
4. **Feature showcase — 3 pillars** (each = a short demo + 3–4 captions):
   - **Review & stage** (lead): file/hunk/line staging, visual line-range, side-by-side↔unified,
     adjustable context, inline image diffs, and **"Review for AI"** (`ay` Yank for AI + `aa` Ask AI).
   - **Inspect history:** log (amend/reword/interactive-rebase/bump from the log), `show`, stash
     split view, path-filtered history.
   - **Manage worktrees:** sync/rebase-status table, create/clone/bulk-delete, `.bare` layout,
     yank/paste between worktrees.
5. **Closing CTA** — install + GitHub.
6. **Footer** — GitHub · Changelog · README · License · **"by David Elentok."**

Cut from the landing page (README only): `gx term`, `doctor`, completions, config schema, `stashify`,
full keybinding tables.
