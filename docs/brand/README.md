# gx brand assets

- `banner-primary.{png,svg}` is layout A and the source for `../banner-1280x640.png`.
- `banner-alternative.{png,svg}` is layout B.
- `lockup-horizontal.png` is the primary mascot + wordmark layout; `lockup-stacked.png` is the secondary layout.
- `wordmark-dark-master.png` and `wordmark-light-master.png` are transparent raster masters for dark and light backgrounds. The AI-generated letterforms are not vector paths.
- `mascot-transparent.png` is the transparent mascot master. `app-icon-1024.png` and both Apple touch icons keep the mascot.
- Browser favicons use the compact `gx` wordmark independently of the Apple touch icons.

Keep the PNG and SVG banner pairs together: the SVG files reference sibling master images.
